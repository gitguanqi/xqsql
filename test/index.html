xqsql 自查索引

三个页面加载同一套用例（core-checks.js），只验证不同的消费路径。全部离线运行，不需要 CDN。

页面

  1. UMD browser.html —— <script> 标签 + 全局 window.xqsql
  2. ESM esm.html —— import 默认导出与命名导出
  3. AMD amd.html —— 本地 require.js 2.3.6

运行方式

npm run test:browser 启动本地服务（默认 http://127.0.0.1:4001/test/），
npm test 跑 Node 侧断言，npm run test:browser:check 用本机浏览器做一次自动验收。

说明

  • 每个页面都会把 PASS / FAIL 写在 #summary，并把生成的 SQL 渲染到 #results。
  • 断言结果同时挂到 window.__XQSQL_TEST__，供 scripts/test-browser.mjs 读取。
  • 页面结束后仍保留可用实例（window.__XQSQL_DEMO__.api），可在控制台继续调用。
